# 文档风格约定

本文档记录 kiaao 引导文档的中英文双语格式规则，供维护者参考。

## 段落组织

- 每个 h2 小节内，英文段落在上，中文段落紧随其后，**之间不插入分隔线**。
- `---` 分隔线**仅用于小节与小节之间**（即一个 h2 内容结束后，下一个 h2 标题之前）。
- 代码块独立放置，在中英文解释之后，不重复出现。

## 标题

- 标题使用双语格式：`English / 中文`。
- 标题层级从 h2 开始，h1 留给页面主标题。

## 代码块

- 代码块不区分语言版本，英文和中文读者共享同一份示例代码。
- 代码块内的注释使用英文，或英文在前、中文在后（行内 `//` 分隔）。

## 引导链接

- 每个文档末尾提供下一篇文档的引导链接，双语格式，`/` 分隔。

## 示例

```
## Definition Mode / 定义模式

English paragraph explaining the concept.

中文段落解释该概念。

代码块
```

---

**注意**：此约定仅适用于 `guide/` 目录下的引导文档。设计笔记和规范文档可独立采用不同的组织方式。
