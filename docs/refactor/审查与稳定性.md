## 发现的问题

### 严重

| #   | 文件                  | 问题                                                                  | 影响                 |
| --- | --------------------- | --------------------------------------------------------------------- | -------------------- |
| S1  | `ssr-helpers.ts`      | `hSSR` 不传 `context` 给组件函数，返回 Promise 的组件只返回 `ssr("")` | SSR 下异步组件无反馈 |
| S2  | `process-children.ts` | 信号值为 `null`/`undefined` 时显示 `"null"`/`"undefined"` 字符串      | 用户体验差           |

### 中等

| #   | 文件                | 问题                                                                   | 影响      |
| --- | ------------------- | ---------------------------------------------------------------------- | --------- |
| M1  | `h.ts`              | 异步组件 resolve 返回 `Comment` 节点时类型标注为 `Element`（类型谎言） | 类型安全  |
| M2  | `h.ts`              | 同步组件 placeholder（`Comment`）强制 cast 为 `Element`                | 类型安全  |
| M3  | `directives.ts`     | `isLazy` 检测过于宽泛——`children[0]` 恰是函数即进入惰性模式            | 意外行为  |
| M4  | `core.ts`           | `recomputeDerivation` 同步递归传播，深度链可栈溢出                     | 稳定性    |
| M5  | `core.ts`           | 无循环依赖检测，用户误用可导致无限循环                                 | 稳定性    |
| M6  | `component.ts`      | `effectStops` 始终为空（v4 无 `effect`），保留但无用                   | 代码冗余  |
| M7  | `async.ts` (romise) | 已移除——v4 异步组件可完全替代                                          | ✅ 已移除 |
| M8  | `ssr-helpers.ts`    | `hSSR` 中异步组件（返回 Promise）静默返回空字符串                      | 违反规范  |

### 低

| #   | 文件                  | 问题                                                                      | 影响     |
| --- | --------------------- | ------------------------------------------------------------------------- | -------- |
| L1  | `process-children.ts` | 信号值为对象时 `String({})` → `"[object Object]"`                         | 不直观   |
| L2  | `props.ts`            | 响应式绑定注销后，对应的 derivation 停止但不清理 `LOCAL_EFFECTS` 外的残留 | 极低     |
| L3  | `teleport.ts`         | target 元素被外部删除后，teleported 内容悬空                              | 边界     |
| L4  | `fragment.ts`         | Fragment 仅 `<div style="display:contents">` 包裹，无其他逻辑             | 设计简单 |
