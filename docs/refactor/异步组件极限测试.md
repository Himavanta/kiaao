# 异步组件极限测试

> 任务：对 v4 异步组件功能做全方位的极限测试。
> 目标：覆盖所有正常路径、边界情况、异常路径、竞态条件。

---

## 测试范围

| 领域             | 覆盖内容                                                       |
| ---------------- | -------------------------------------------------------------- |
| **基础渲染**     | resolve 后渲染、wrapper 行为、多次 resolve                     |
| **生命周期**     | onMount 延迟触发、onUnmount 注册时机、嵌套生命周期顺序         |
| **竞态条件**     | resolve 前卸载、resolve 后立即卸载、并行 resolve、多级异步嵌套 |
| **错误处理**     | reject、throw、非 Node resolve、loader 异常                    |
| **SSR**          | 抛错、mode 恢复                                                |
| **嵌套组合**     | 同步包异步、异步包同步、异步包异步、多层嵌套                   |
| **资源清理**     | resolve 前清理、resolve 后清理、深层子树清理                   |
| **与指令协作**   | when + 异步组件、each + 异步组件                               |
| **真实场景模拟** | 网络延迟、超时、重试、数据依赖链                               |
