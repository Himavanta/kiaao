# when/each 指令极限测试

> 任务：对 `when` 和 `each` 指令做全方位的极限测试。
> 目标：覆盖所有正常路径、边界情况、异常路径、组合场景，防止类似 `when` + 异步组件的 bug 再次漏掉。

---

## 测试范围

| 领域                 | 覆盖内容                                           |
| -------------------- | -------------------------------------------------- |
| **when: 信号条件**   | 创建到切换、快速切换、切换中间态、异步组件         |
| **when: 非信号条件** | 静态值、普通函数（一次性）、undefined 等价于没传   |
| **when: 映射表模式** | 多分支、切换、缺失 key、动态表、else               |
| **when: 资源清理**   | 分支切换后旧绑定停止、嵌套组件 onUnmount、异步清理 |
| **each: 基本渲染**   | 数组、Map、Set、Number、String、Object             |
| **each: 响应式更新** | 增删改、信号源变 null/undefined、源替换            |
| **each: key 行为**   | 稳定 key、不稳定 key、重复 key、无 key             |
| **each: 资源清理**   | item 信号清理、DOM 清理、嵌套组件卸载              |
| **each: 错误恢复**   | childFn 抛错后的后续 item 渲染                     |
| **when + each 组合** | when 守卫 each、each 内 when、多层嵌套             |
| **极限/压力**        | 大量 item、快速切换、大 key 数据集                 |
