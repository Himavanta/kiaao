## 各文件产物

### 1. `types.ts`

```ts
export interface RouteMap {
  [key: string]: ComponentFunction | RouteMap;
}

export interface RouterOptions {
  routes: RouteMap;
  onRoute?: (to: string, from: string | null) => string | void | Promise<string | void>;
}

export interface Router {
  Router: ComponentFunction;
  Link: ComponentFunction;
  push: (path: string) => Promise<void>;
  current: Signal<string>;
  search: Signal<Record<string, string>>;
}
```

### 2. `utils.ts`

复用 v1 算法：

```ts
export function getPathname(): string;
export function getSearch(): string;
export function pushState(path: string): void;
export function parseSearch(s: string): URLSearchParams;

export function extractSegment(fullPath: string, base?: string): string | null;
```

### 3. `route-group.ts`

内部实现：

```ts
// 不导出
function RouteGroup(props, context): HResult;

// 不导出
function createRouterView(opts: {
  base: string;
  others: RouteMap;
  current: Signal<string>;
}): (props, context) => HResult;
```

### 4. `link.ts`

```ts
export function createRouterLink(push: (path: string) => Promise<void>): ComponentFunction;
```

`to` 支持：

- `string`
- `Signal<string>`

### 5. `router.ts`

```ts
export function createRouter(options: RouterOptions): Router;
```

实现要点：

- 运行时校验 `routes[""]` 是函数
- 顶层 `Router` 组件 = `RouteGroup({ routes, base: "/", current })`
- 派生 `current` 与 `search` 为逻辑只读信号（按 `guide/reactivity.md` 的模式）
- 首次进入触发 `onRoute(initialPath, null)`
- `popstate` 触发 `onRoute(current, _url())`，通过后 `replaceState`
- `push` 触发 `onRoute(path, _url())`，通过后 `pushState`
- 重定向链 ≤ 10 次

### 6. `index.ts`

```ts
export { createRouter } from "./router.ts";
export type { Router, RouterOptions, RouteMap, RouterLinkProps } from "./types.ts";
```
