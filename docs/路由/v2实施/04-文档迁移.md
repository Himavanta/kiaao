## `packages/example` 迁移

示例当前用：

```ts
import { createRouter } from "kiaao/router";
const { RouterView, Link, navigate, currentPath } = createRouter({...});
```

迁移后：

```ts
import { createRouter } from "kiaao/router";
const { Router, Link, push, current, search } = createRouter({
  routes: { ... },
  onRoute?: ...,
});
function App() {
  return <Router />;
}
```

注意：

- 嵌套对象路由（替换 Route[]）
- 顶层 `<Router />` 替换 `<RouterView routes=...>`
- `navigate(...)` → `push(...)`
- `currentPath()` → `current()`
- 路由 layout 内接收 `RouterView` props
