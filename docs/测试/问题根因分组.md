# 问题根因分组分析

基于 30 个暴露问题的触发模式与框架响应，归纳为 6 个根因分组 + 1 个非 bug 分组。

---

## 分组 A：信号系统（7 个问题）

**根因**：`signal.ts` 中派生追踪、依赖收集、停止清理存在缺陷。

| #   | 问题                     | 具体表现                                                                              |
| --- | ------------------------ | ------------------------------------------------------------------------------------- |
| 7   | 派生链深度传播失败       | 10 层链中值未传播到底层                                                               |
| 19  | 派生链传播失败           | 同 #7，不同测试路径复现                                                               |
| 27  | 100 层派生链传播失败     | 同 #7，更深层复现                                                                     |
| 20  | 钻石依赖冗余计算         | A→B, A→C, B+C→D 时 D 重复计算                                                         |
| 17  | 信号清理 stop 未生效     | `disposeOwner` 执行了 cleanups，但 signal 的 sub set 未清理，派生仍响应。**内存泄漏** |
| 2   | dispose 后信号订阅未停止 | 同 #17，不同测试路径                                                                  |
| 8   | SSR 模式下派生只计算一次 | `createStaticDerived` 跳过依赖追踪                                                    |

**可能根因**：`stop()` 函数在执行后未从 `state.subs` 中移除自身？或者 `triggerDerivations` 的 `[...state.subs]` 快照包含了已 stop 的 derivation？

---

## 分组 B：DOM 元素无 Owner / nestBind 架构（5 个问题）

**根因**：`handleDomMode` 返回 `createHResult(null, [el])`，DOM 元素不挂 Owner。`nestBind` 架构下此设计导致 Owner 链在某些路径中断。

| #   | 问题                           | 具体表现                                                                 |
| --- | ------------------------------ | ------------------------------------------------------------------------ |
| 1   | disposeOwner 后元素未清理      | `handleDomMode` 返回的 HResult `owner=null`, 元素不被任何 Owner 跟踪     |
| 4   | 组件实例间 onMount 不触发      | `h("div", null, h(A), h(B))` 中 div 无 Owner → triggerMount 无法到达 A/B |
| 6   | 100 children 渲染测试失败      | `mount` 的 `triggerMount` 路径不正确（关联 #4）                          |
| 18  | 深层组件树 dispose 后 DOM 残留 | 多层 DOM 嵌套后 disposeOwner 遍历不到所有元素                            |
| 29  | 嵌套空 div 渲染                | `childResults=[]` 时元素本身未 append                                    |

---

## 分组 C：nestBind 防御不足（3 个问题）

**根因**：`nestBindResult` / `nestBindPrimitive` 中未充分处理边界值。

| #   | 问题                        | 具体表现                                                   |
| --- | --------------------------- | ---------------------------------------------------------- |
| 3   | `true` 渲染为 `"true"` 文本 | `nestBindPrimitive` 只过滤 `isNil`，`true` 进入 `String()` |
| 5   | 空字符串 tag                | `adapter.el("")` 创建无效 `< >` 元素                       |
| 30  | 组件返回混合数组            | `[null, h("span"), undefined, false]` 中 nestBind 处理异常 |

---

## 分组 D：Adapter API 防御不足（3 个问题）

**根因**：DOM adapter 的几个方法对非法参数缺少类型守卫。

| #   | 问题                                   | 具体表现                                              |
| --- | -------------------------------------- | ----------------------------------------------------- |
| 11  | `adapter.remove(null)` 崩溃            | `(null as ChildNode).remove()` → TypeError            |
| 12  | `adapter.append(textNode, child)` 崩溃 | `textNode.append(child)` → DOMException               |
| 13  | `adapter.clear(textNode)` 崩溃         | `(textNode as Element).replaceChildren()` → TypeError |

---

## 分组 E：指令系统（3 个问题）

**根因**：`handleDirectiveMode` 中指令函数调用缺少异常保护，且指令 Owner 在 Owner 树中未正确连接。

| #   | 问题                  | 具体表现                                                 |
| --- | --------------------- | -------------------------------------------------------- |
| 14  | 指令抛异常未捕获      | 指令内 `throw` 未被 try/catch 兜底                       |
| 15  | 指令嵌套 onMount 顺序 | 外层指令和内层指令的 mount 顺序与预期不符                |
| 16  | 指令 onUnmount 未触发 | `directiveOwner` 未连到 Owner 树 → disposeOwner 遍历不到 |

---

## 分组 F：SSR 渲染（2 个问题，7 种子场景）

**根因**：`server/adapter.ts` 的 setProp 和序列化逻辑。

| #   | 问题                            | 具体表现                                                                   |
| --- | ------------------------------- | -------------------------------------------------------------------------- |
| 10  | style 对象序列化格式            | `{color:"red"}` → `{"color":"red"}`（JSON）应 → `color: red`               |
| 21  | SSR renderToString 边界（7 种） | 特殊字符未转义、void 元素未自闭合、布尔属性 false 仍输出、事件 prop 未跳过 |

---

## 修复优先级建议

| 优先级 | 分组               | 理由                                    |
| ------ | ------------------ | --------------------------------------- |
| 🔴 P0  | A 信号系统         | 内存泄漏 + 派生链错误影响所有功能       |
| 🔴 P0  | F SSR 渲染         | 输出格式错误影响生产 SSR                |
| 🟠 P1  | E 指令系统         | 异常传播和生命周期错误                  |
| 🟠 P1  | B DOM 元素无 Owner | 影响 triggerMount 可达性和 dispose 清理 |
| 🟡 P2  | C nestBind 防御    | `true` 渲染、空 tag 等边界              |
| 🟡 P2  | D Adapter 防御     | null 参数保护（易修、影响小）           |
| ⚪ —   | G 非 bug           | 测试调整或文档说明即可                  |
