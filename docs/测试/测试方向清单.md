# 尚未覆盖的测试方向

基于 `TESTING.md` 准则和已完成测试的审计，以下方向尚未覆盖或仅浅层覆盖。

---

## P0 — 应该覆盖

### 1. Motion 动画系统

createMotion / createGroupMotion 的极端场景：

- 动画帧时序：快速 toggle 时动画未完成就被中断
- `playEnterAnimation` 与 `collectExitAnimations` 在 dispose 时的竞争
- 大量元素同时播放动画（100 个元素 group motion）
- `from`/`to` 配置为 null/undefined/空对象
- 动画回调（`onfinish`）中修改信号
- 动画元素在播放中被 remove

### 2. Portal

Portal 极端场景：

- target 元素在 portal 挂载后被移除
- 多个 Portal 到同一 target
- Portal 嵌套 Portal
- Portal 在 SSR 下的行为
- `createApp` unmount 时 Portal 内容的清理

### 3. Lazy

Lazy 极端场景：

- loader 超时（永不 resolve）
- loader resolve 非组件值
- 多个 lazy 组件同时加载
- lazy 组件在 resolve 前被 dispose
- lazy 组件内调用 `context.onMount`
- SSR 环境下的 lazy

### 4. Router 深度

Router 更多测试：

- 嵌套路由参数传递
- 路由切换时旧组件的 `onUnmount` 与新组件的 `onMount` 时序
- 路由表动态替换
- 路径参数含特殊字符（`/`, `%`, `?`, `#`）
- Link 组件在 dispose 后点击
- `navigate` 在信号回调中调用
- `currentPath` 信号在路由切换时的更新顺序

---

## P1 — 值得覆盖

### 5. JSX Runtime

`jsx-runtime/index.ts` 的边界：

- `createJsxElement` 传 null/undefined type
- `normalizeChildren` 处理各种 JSX children 模式（嵌套数组、函数 children、null 等）
- `key` prop 的处理
- Fragment 的多种调用方式
- spread props（`{...rest}`）含事件/样式/特殊 key

### 6. Astro 集成

`src/astro/` 模块：

- `client.ts` 的 hydration 逻辑
- `server.ts` 的 SSR 集成
- Astro `server:start` 等生命周期集成

### 7. Adapter 热切换

渲染过程中切换 adapter：

- 在 `triggerMount` 执行中途切换 adapter
- 不同 adapter 之间的状态隔离
- SSR adapter 下调用 DOM 方法（已有基础测试，可加深）

### 8. 信号批量更新

信号系统：

- 多个信号同时写入时的合并行为
- 派生函数中批量修改多个信号
- 信号写入导致派生链重算，派生链重算中又写入其他信号
- 1000 个信号同时触发的派生

### 9. DOM 事件深度

事件传播：

- `stopPropagation()` 在 onClick 中的效果
- `preventDefault()` 在 form submit 等场景
- passive event listeners
- 自定义事件 dispatch
- 事件在 dispose 后的清理

## P2 — 有则更好

### 10. 组件纯度 / identity

- 相同 props 是否返回相同树（引用不变性）
- 无状态组件多次渲染的稳定性

### 11. 递归组件

- 组件内部引用自身（需要条件终止）
- 极端：递归组件深度 100 层时能否提前终止

### 12. 大量 DOM 操作

- 10,000 个元素同时创建/挂载的性能
- 频繁信号更新导致大量 DOM 重绘

### 13. CSS / 样式

- class 动态切换
- inline style 增量合并在复杂对象上的行为
- CSS 变量作为属性值

### 14. 跨框架互操作

- 在 kiaao 组件内部使用原生 Web Component
- 在原生 DOM 中挂载 kiaao 组件树
- 多个框架实例共存

### 15. SSR 深度

- SSR + hydrate 的一致性
- SSR 输出中自定义 data-\* 属性
- SSR 输出含超大文本/属性值
- SSR + 动态组件（async/lazy）

### 16. TypeScript 类型

- `h()` 的泛型类型推导
- `ComponentFunction<P>` 的 props 类型
- 控制流组件的 children 类型
- `DirectiveFunction` 参数类型

### 17. 竞态/时序

- 信号回调中修改 props.value 导致 Show 重入
- 组件 dispose 与信号回调的时序竞争
- `setTimeout` / `requestAnimationFrame` 内修改信号

### 18. 属性前缀（attr:/prop:）

- `attr:` 在 SVG 元素上的行为
- `prop:` 在自定义元素上的行为
- 混合使用 `attr:` 和直接属性

### 19. HTTP / 网络

- lazy 组件加载失败（404）
- 异步信号（如果支持）的 timeout
- 派生依赖外部数据源

---

## 优先级建议

| 批次    | 方向                     | 理由                          |
| ------- | ------------------------ | ----------------------------- |
| 第 1 批 | Motion、Portal、Lazy     | 已有 DOM 实现，是最常用的扩展 |
| 第 2 批 | Router 深度、JSX Runtime | 影响开发者体验                |
| 第 3 批 | 信号批量、事件深度       | 影响运行时正确性              |
| 第 4 批 | Astro、适配器热切换      | 集成场景                      |
| 第 5 批 | 其余 P2 方向             | 有则更好                      |
