# 尚未覆盖的测试方向

基于 `TESTING.md` 准则和已完成测试的审计，以下方向尚未覆盖或仅浅层覆盖。

---

## P0 — 应该覆盖

### 1. Motion 动画系统

createMotion / createGroupMotion 的极端场景：

- 动画帧时序：快速 toggle 时动画未完成就被中断
- `playEnterAnimation` 与 `collectExitAnimations` 在 dispose 时的竞争
- 大量元素同时播放动画（100 个元素 group motion）
- `from`/`to` 配置为 null/undefined/空对象
- 动画回调（`onfinish`）中修改信号
- 动画元素在播放中被 remove

### 2. Portal

Portal 极端场景：

- target 元素在 portal 挂载后被移除
- 多个 Portal 到同一 target
- Portal 嵌套 Portal
- Portal 在 SSR 下的行为
- `createApp` unmount 时 Portal 内容的清理

### 3. Lazy

Lazy 极端场景：

- loader 超时（永不 resolve）
- loader resolve 非组件值
- 多个 lazy 组件同时加载
- lazy 组件在 resolve 前被 dispose
- lazy 组件内调用 `context.onMount`
- SSR 环境下的 lazy

### 4. Router 深度

Router 更多测试：

- 嵌套路由参数传递
- 路由切换时旧组件的 `onUnmount` 与新组件的 `onMount` 时序
- 路由表动态替换
- 路径参数含特殊字符（`/`, `%`, `?`, `#`）
- Link 组件在 dispose 后点击
- `navigate` 在信号回调中调用
- `currentPath` 信号在路由切换时的更新顺序

---

## P1 — 值得覆盖

### 5. JSX Runtime

`jsx-runtime/index.ts` 的边界：

- `createJsxElement` 传 null/undefined type
- `normalizeChildren` 处理各种 JSX children 模式（嵌套数组、函数 children、null 等）
- `key` prop 的处理
- Fragment 的多种调用方式
- spread props（`{...rest}`）含事件/样式/特殊 key

### 6. Astro 集成

`src/astro/` 模块：

- `client.ts` 的 hydration 逻辑
- `server.ts` 的 SSR 集成
- Astro `server:start` 等生命周期集成

### 7. Adapter 热切换

渲染过程中切换 adapter：

- 在 `triggerMount` 执行中途切换 adapter
- 不同 adapter 之间的状态隔离
- SSR adapter 下调用 DOM 方法（已有基础测试，可加深）

### 8. 信号批量更新

信号系统：

- 多个信号同时写入时的合并行为
- 派生函数中批量修改多个信号
- 信号写入导致派生链重算，派生链重算中又写入其他信号
- 1000 个信号同时触发的派生

### 9. DOM 事件深度

事件传播：

- `stopPropagation()` 在 onClick 中的效果
- `preventDefault()` 在 form submit 等场景
- passive event listeners
- 自定义事件 dispatch
- 事件在 dispose 后的清理

## P2 — 有则更好

### 10. 组件纯度 / identity

- 相同 props 是否返回相同树（引用不变性）
- 无状态组件多次渲染的稳定性
- 组件引用 identity 在信号更新后是否保持不变

**估算**：~10 测试，简单

### 11. 递归组件

- 组件内部引用自身（需要条件终止）
- 递归深度 10 层 / 50 层 / 100 层的渲染正确性
- 递归组件 dispose 后 DOM 正确清理
- 递归组件配合 Show/Each 控制流
- 递归深度超出调用栈时的错误处理

**估算**：~8 测试，中等（递归终止条件需设计）

### 12. 大量 DOM 操作

- 10,000 个 `<span>` 同时创建/挂载
- 频繁信号更新（1000 次）导致大量 DOM 节点重绘
- 10,000 个元素的 Fragment 一次性挂载
- 大量元素叠加 style 动态绑定
- 超大列表（10,000 项）的 Each 渲染与重排

**注意**：部分测试在 happy-dom 中可能因性能问题不可行，需设置超时时间或标记为浏览器环境测试

**估算**：~6 测试，涉及 CI 超时风险

### 13. CSS / 样式

- `class` 字符串动态切换
- `className` 属性（JSX 兼容）
- `classList` 对象赋值
- inline style 字符串设置
- inline style 对象增量合并：
  - 简单对象 `{ color: "red" }`
  - 嵌套属性 `{ transform: "scale(2)" }`
  - CSS 变量 `{ "--custom": "10px" }`
  - 空对象 `{}`
  - 含连字符的 key（`background-color` vs `backgroundColor`）
- style 信号绑定：信号变化时增量合并
- style dispose 后清理
- 多个 style 更新合并到同一帧

**估算**：~15 测试，中等

### 14. 跨框架互操作

- 在 kiaao 组件内使用原生 Web Component（自定义元素）
- 在 kiaao 组件内渲染原生 DOM API 创建的节点
- 原生 DOM 中挂载 kiaao 组件树（`createApp` 到任意容器）
- 多个 kiaao `createApp` 实例在同一个页面共存
- kiaao 与 React/Vue 在同一页面时的互操作（事件冒泡、DOM 竞争）

**注意**：跨框架测试需要多框架运行时环境，适合 e2e 而非 unit

**估算**：~5 测试，简易（基本场景 unit 可测，复杂场景需 e2e）

### 15. SSR 深度

已有基础（`tests/server/ssr.test.ts` + `tests/core/ssr-mix.test.ts`），补充：

- SSR 输出中自定义 `data-*` 属性
- SSR 输出含超大文本（10KB+）
- SSR + 动态组件标记（序列化占位符）
- SSR + hydrate 的节点匹配（当前未实现 hydrate，可标记为未来）
- SSR 下特殊字符：HTML 实体、Unicode、emoji、零宽字符
- SSR 下 SVG 元素序列化
- SSR 下 boolean 属性（`disabled`、`checked`、`selected`、`hidden`）
- SSR 下 `style` 对象 vs 字符串的差异
- SSR `renderToString` 在组件抛异常时的容错
- SSR 下 `getAdapter().off()` 的行为（当前是 no-op）

**注意**：当前 SSR 的 `style` 序列化行为（`attrToString` 输出 JSON）与预期 CSS 格式不一致，已在 P0 问题列表中

**估算**：~15 测试，中等

### 16. TypeScript 类型

- `h()` 的泛型类型推导：`h(Comp, props)` 中 props 类型自动推断为 Comp 的参数
- `ComponentFunction<P>` 的 props 类型：`P extends Record<string, any>` 约束
- 控制流组件的 children 类型：`Show` 的 `primary`/`fallback` 类型
- `DirectiveFunction` 参数类型
- `Signal<T>` 作为 getter/setter 的统一类型
- `MaybeSignal<T>` 在控制流组件 props 中的正确推导
- `h()` 的 string tag 返回类型 vs function tag 返回类型的一致性

**注意**：类型测试不在 runtime 而是在 `tsc --noEmit` 层面，当前 `vp check` 已覆盖

**估算**：~10 类型测试（`expectTypeOf` 或 `ts-expect-error`），中等

### 17. 竞态/时序

- 信号回调中修改 `props.value` 导致 Show 重入
- 组件 dispose 与信号回调的时序竞争
  - dispose 后信号回调是否执行
  - dispose 执行中信号回调注册新的 onMount
- `setTimeout` 内修改信号后触发派生链
- `requestAnimationFrame` 内修改信号（happy-dom 不支持 rAF）
- 多个 `use()` 监听同一源信号，其中一个 dispose 后其他是否受影响
- `disposeOwner` 在派生计算执行中途调用

**估算**：~12 测试，中等难度

### 18. 属性前缀（attr:/prop:）

- `attr:` 在 SVG 元素上设置 `viewBox`、`d` 等属性
- `prop:` 在自定义元素上设置复杂属性（对象/数组）
- `attr:` 与普通属性混合使用时的覆盖规则
- `attr:` 在信号绑定下的更新
- SSR 下 `attr:` / `prop:` 前缀的处理

**估算**：~8 测试，简单

### 19. HTTP / 网络

- lazy 组件加载 404（loader 返回 rejected promise）→ 已有覆盖
- lazy 组件加载超时（loader 永不 resolve）→ 已有覆盖
- 异步信号的 timeout
- 派生依赖外部数据源（如 fetch）

**注意**：HTTP 测试依赖 mock server 或 fetch polyfill，当前 happy-dom 环境不完整

**估算**：~5 测试（补充边界即可），简单
