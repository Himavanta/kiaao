## 一、动机

当前测试按功能垂直划分：控制流组件单独测、异步组件单独测、指令单独测。但在真实应用中，这些功能是**组合使用**的——列表项内有条件渲染、条件渲染内含异步加载、异步加载后应用动画等。

组合场景最容易暴露 Owner 链断裂、信号泄漏、生命周期错乱等跨模块问题，但当前完全无覆盖。

---

## 二、目标

创建一个混合嵌套测试文件，覆盖以下组合场景：

| 优先级 | 组合                                      | 真实场景对应                |
| ------ | ----------------------------------------- | --------------------------- |
| P0     | Show + Async                              | 条件渲染的异步加载区块      |
| P0     | Each + Show                               | 列表项内条件渲染            |
| P0     | Each + Show + Async                       | 列表项内有条件异步加载      |
| P1     | Each + 指令 + Show                        | 指令包裹条件渲染项          |
| P1     | Async + Each + Show                       | 异步组件 resolve 后渲染列表 |
| P2     | Portal + Show + 组件                      | Portal 内条件渲染           |
| P2     | 综合压力：Each + Show + Directive + Async | 全链路                      |

## 三、测试场景设计

### 场景 1：Show > Async 切换

```tsx
<Show value={visible}>
  {() => <AsyncComp />}
  {() => <div>fallback</div>}
</Show>
```

**验证点**：

- 首次渲染 AsyncComp 显示 placeholder
- resolve 后内容替换 placeholder
- Show 切到 fallback 时 AsyncComp 的 Owner 被 dispose
- 切回 primary 时 AsyncComp 重新创建

---

### 场景 2：Each > Show 条件列表

```tsx
<Each value={items} keyed={(i) => i.id}>
  {({ item }) => <Show value={item().active}>{() => <div>{item().text}</div>}</Show>}
</Each>
```

**验证点**：

- 列表渲染时每项的条件渲染独立
- 信号驱动每项切换
- 列表重排时条件状态保持

---

### 场景 3：Each > Show > Async 列表项异步加载

```tsx
<Each value={items}>
  {({ item }) => (
    <Show value={item().loaded}>
      {() => <AsyncDetail id={item().id} />}
      {() => <div>loading...</div>}
    </Show>
  )}
</Each>
```

**验证点**：

- 每个列表项独立异步加载
- 加载完成后各自替换 placeholder
- 列表重排时项的内部状态保持

---

### 场景 4：Each > 指令 > Show

```tsx
<Each value={items}>
  {({ item }) => (
    <FadeIn>
      <Show value={item().active}>{() => <div>{item().text}</div>}</Show>
    </FadeIn>
  )}
</Each>
```

**验证点**：

- 指令在 Each 条目内正常挂载
- Show 切换时指令 onUnmount 触发
- 列表重排时指令生命周期正确

---

### 场景 5：Async > Each > Show

```tsx
<AsyncComp>
  {/* resolve 后渲染列表 */}
  <Each value={items}>
    {({ item }) => <Show value={item().active}>{() => <div>{item().text}</div>}</Show>}
  </Each>
</AsyncComp>
```

**验证点**：

- 异步组件 resolve 后完整渲染多层嵌套
- 嵌套内的信号绑定工作正常
- dispose 级联正确

---

### 场景 6：Portal > Show > 组件

```tsx
<Portal to="body">
  <Show value={visible}>{() => <div>portal content</div>}</Show>
</Portal>
```

**验证点**：

- Show 在 Portal 内正常渲染
- Show 切换时 Portal 内容更新
- Portal unmount 时 Show 内容清理

---

### 场景 7：综合压力

```tsx
<Each value={sections}>
  {({ section }) => (
    <FadeIn>
      <Show value={section().expanded}>
        {() => (
          <div>
            <h3>{section().title}</h3>
            <Each value={section().items}>{({ item }) => <AsyncDetail id={item().id} />}</Each>
          </div>
        )}
      </Show>
    </FadeIn>
  )}
</Each>
```

**验证点**：

- 全链路多层嵌套下整体渲染正确
- 任意层信号更新传播正常
- 整体 dispose 无泄漏
