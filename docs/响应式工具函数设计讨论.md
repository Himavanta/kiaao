# 响应式工具函数设计讨论

**状态**：待定  
**日期**：2026-06-09

## 一、问题

kiaao 的组件只执行一次，props 在初始化时传入。父组件可以传入普通值或响应式 getter：

```tsx
// 静态值
<Icon icon="mdi:home" />;

// 响应式值
const [current, setCurrent] = define("mdi:home");
<Icon icon={current} />;
```

组件内部接收 props，但不知道 `props.icon` 是 `string` 还是 `Getter<string>`。在 `effect` 中消费时，如果它是 getter，需要调用它（追踪依赖）；如果它是值，直接使用：

```tsx
effect(() => {
  // props.icon 可能是字符串也可能是 getter
  const name = typeof props.icon === "function" ? props.icon() : props.icon;
  fetchIcon(name).then(...)
});
```

每个接收响应式 props 的组件都要重复这种判断，违反 DRY 原则。

## 二、需要什么

### 核心能力

1. **安全取值**：不管传入的是什么，能拿到值，同时在 effect 中自动追踪依赖
2. **类型友好**：不需要额外的类型体操

### 不需要的

- `toRef` / `toRefs` — 将对象属性转为 getter，在 kiaao 中不需要（可以直接传 getter）
- `unref` / `isRef` — Vue 风格的命名，语义不清
- `watch` — kiaao 的 `effect` 已覆盖
- `computed` — kiaao 的 `derive` 已覆盖

## 三、建议方案

提供两个函数：

### `read(v)`

读取一个值。如果是 getter 则调用它（在 effect/derive 中自动追踪依赖），否则原样返回。

```ts
function read<T>(v: T | Getter<T>): T {
  return typeof v === "function" && (v as any)[IS_REACTIVE] ? (v as Getter<T>)() : v;
}
```

使用场景：在 `effect`、`derive`、`@each` 渲染函数中读取未知类型的值。

```tsx
function Icon(props) {
  effect(() => {
    const name = read(props.icon);  // string | Getter → string
    fetchIcon(name).then(...)
  });
  // ...
}
```

### `source(v)`

把一个值确保包装为 getter。如果已经是 getter 则原样返回，如果是普通值则用 `derive` 包一层，使其可以被 `read()` 解包，也可以作为 getter 传递。

```ts
function source<T>(v: T | Getter<T>): Getter<T> {
  return typeof v === "function" && (v as any)[IS_REACTIVE] ? (v as Getter<T>) : () => v as T;
}
```

使用场景：需要把 props 存下来给多处使用，统一按 getter 处理。

```tsx
function Icon(props) {
  const iconName = source(props.icon);
  // iconName 一定是 getter

  effect(() => {
    fetchIcon(iconName()).then(...)
  });

  const body = derive(() => {
    return iconName() ? fetchFromCache(iconName()) : "";
  });
}
```

## 四、备选命名

### `read(v)`

|   候选    | 评价                                 |
| :-------: | :----------------------------------- |
|  `read`   | 简洁，动词明确：读一个值             |
| `resolve` | 长了一点                             |
|   `get`   | 太通用，可能冲突                     |
| `unwrap`  | 暗示了某种包装，但值不一定是被包装的 |
|   `val`   | Vue 用过，容易混淆                   |

### `source(v)`

|    候选    | 评价                 |
| :--------: | :------------------- |
|  `source`  | 暗示"确保它是数据源" |
| `toGetter` | 太长，但语义最准确   |
|  `derive`  | 已被占用，行为也不同 |
|  `ensure`  | 暗示"确保是响应式的" |

## 五、实现位置

放在 `src/core/runtime.ts` 或独立的 `src/core/utils.ts`，从 `src/index.ts` 导出。

依赖：

- `IS_REACTIVE` Symbol（types.ts）
- `typeof === "function"` 判断（不需要额外依赖）
