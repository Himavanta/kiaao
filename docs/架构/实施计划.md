# 跨端架构重构 —— 实施计划

> 基于 `docs/架构/跨端架构重构方案.md` 的逐步骤实施规划
> 原则：每完成一个步骤，`vp check --fix src/` 零错误 + `vp test` 全绿

---

## Phase 0：准备（基础设施搭建）

### Step 0.1 创建 `adapter/` 目录

**目标：** 将全局配置从 core 剥离到独立目录。

**具体改动：**

- 创建 `src/adapter/index.ts`
- 从 `src/core/types.ts` 移入：`setAdapter`、`getAdapter`、`removeNode`
- 从 `src/core/signal.ts` 移入：`RenderMode` 类型、`setRenderMode`、`getRenderMode`、`currentRenderMode` 变量
- 更新所有 import 路径（`core/types.ts` 中原引用 → `adapter/index.ts`）

**涉及文件：** `core/types.ts`、`core/signal.ts`、`server/index.ts`、`dom/lazy.ts`、`src/index.ts` + 新建 `adapter/index.ts`

**验证：** `vp check --fix src/` 零错误

---

### Step 0.2 `core/types.ts`：`HostNode` + `RenderAdapter` 更新

**目标：** 定义抽象类型，移除 DOM 类型引用。

**改动：**

1. 新增 `type HostNode = unknown`
2. `HResult.nodes: Node[]` → `HostNode[]`
3. `RenderAdapter` 接口中所有 `Node` / `Element` → `HostNode`
4. `RenderAdapter` 新增方法：
   - `isNode(value: unknown): value is HostNode`
   - `createStaticDerived?<T>(fn: (...args: any[]) => T, deps: Signal<any>[]): Signal<T>`
5. 删除 `removeNode`（已移至 `adapter/index.ts`）
6. 删除 `setAdapter` / `getAdapter`（已移至 `adapter/index.ts`）

**验证：** 仅改类型，不改实现。`vp check --fix src/` 零错误。

---

### Step 0.3 `signal.ts`：移除 SSR 优化，改用 `createStaticDerived`

**目标：** `derivationMode` 中不再检查 `RenderMode`，改用 adapter 钩子。

**改动：**

```ts
// 改前
if (currentRenderMode === "ssr") {
  const value = func(undefined);
  return definitionMode(value);
}

// 改后
const adapter = getAdapter();
if (adapter.createStaticDerived) {
  return adapter.createStaticDerived(func, validDeps);
}
```

删除导出：`RenderMode`、`setRenderMode`、`getRenderMode`（已移至 `adapter/index.ts`）

---

### Step 0.4 `core/props.ts`：从 `dom/props.ts` 剥离通用逻辑

**目标：** 创建 core 层的 `setProps`，DOM 特有的 style 处理下沉到 `dom/adapter.ts`。

**改动：**

1. 新建 `src/core/props.ts`
2. 从 `dom/props.ts` 移入 `setProps`（只保留迭代 + 响应式逻辑，去掉 style 对象特殊处理）
3. `dom/props.ts` 的 style 处理移到 `dom/adapter.ts` 的 `setProp` 方法中
4. `dom/props.ts` 标记为即将删除

**验证：** `setProps` 在 core 层正常导出，`handleDomMode` 能从 core 导入。

---

### Step 0.5 `type-guards.ts` 拆分

**目标：** 通用检查留在 core，平台检查移到 dom。

**改动：**

1. 新建 `src/core/type-guards.ts`：`isString` / `isFunction` / `isNil` / `isArray` …（不含 `isNode`/`isElement`）
2. 新建 `src/dom/type-guards.ts`：`isNode` / `isElement` / `isSVGElement`
3. 更新所有 import 路径（core 中的 `isNode`/`isElement` 引用改为 `adapter.isNode()`）
4. 删除 `src/utils/type-guards.ts`

**注意：** `process-children.ts` 中 `isNode(child)` 改为 `adapter.isNode(child)`——但这依赖 Step 1.1。

---

### Step 0.6 更新 DOM / SSR adapter 实现

**目标：** 让 adapter 实现匹配更新后的 `RenderAdapter` 接口。

**改动：**

- `dom/adapter.ts`：实现 `isNode` 方法；`setProp` 中增加 style 对象 → `Object.assign(elStyle, value)` 处理
- `server/adapter.ts`：实现 `isNode` 方法；实现 `createStaticDerived` 方法；`setProp` 中增加 style → cssText 序列化
- 两个 adapter 的方法签名：`Node` / `Element` → `HostNode`

---

## Phase 1：消除 core 对 dom 的依赖

### Step 1.1 `directives.ts`：移除 DOM 直调

- `el.append(node)` → `adapter.append(el, node)`
- `anchor.before(n)` → `adapter.before(anchor, n)`
- 去掉 `clearElement(el)`（`disposeOwner` 已覆盖）
- 简化 `repositionItemGroup`（去掉 `.firstChild` / `.previousSibling` 位置判断，直接 `adapter.before`）
- 所有 `el: Element` → `el: HostNode`

### Step 1.2 `process-children.ts`：`adapter.isNode()`

- `isNode(child)` → `adapter.isNode(child)`
- 去掉 SSR 节点 `"type" in child` 特殊判断（`adapter.isNode` 统一处理）

### Step 1.3 `h.ts` / `component.ts` / `create-app.ts`

- `h.ts`：`handleDomMode` 中 `el: any` → `HostNode`
- `component.ts`：`mergeResults` / `handleAsyncComponent` 中 `Node[]` → `HostNode[]`
- `create-app.ts`：`nodes: Node[]` → `HostNode[]`

### Step 1.4 删除 `dom/props.ts`

验证 `setProps` 已从 `core/props.ts` 正确导入。

### Step 1.5 最终验证

```bash
grep -rn "Node\|Element" src/core/ --include='*.ts' | grep -v "HostNode\|\.d\.ts\|node_modules\|//\|type-guards\|import\|isNode"
```

确认 core/ 无 DOM 类型引用。

## Phase 2：入口整合

### Step 2.1 `src/index.ts`

```ts
import { setAdapter } from "./adapter/index.ts";
import { domAdapter } from "./dom/adapter.ts";
try {
  if (globalThis.document) setAdapter(domAdapter);
} catch {}
export * from "./core/index.ts";
export * from "./dom/index.ts";
```

### Step 2.2 `server/index.ts`

```ts
import { setAdapter, setRenderMode } from "../adapter/index.ts";
import { ssrAdapter } from "./adapter.ts";
setAdapter(ssrAdapter);
setRenderMode("ssr");
export { renderToString } from "./index.ts";
```
