### 1. 指令模式返回单 Node 与数组的消费者兼容性

**发现时间**：2026-06-14（阶段 0 审查）
**状态**：待确认

`h()` 的指令模式始终返回 `children`（rest 参数数组）。但当前的消费者（`each` 的 `renderEach`、`when` 的惰性分支）使用 `node instanceof Node` 做类型判断，无法处理数组返回值。

**建议方案**：指令模式在单子节点时直接展开返回 Element，多子节点时返回数组。

```ts
// 指令模式末尾
if (flatChildren.length === 1 && flatChildren[0] instanceof Node) {
  return flatChildren[0] as unknown as Element;
}
return children as unknown as Element;
```

**影响范围**：

- `each` 的 `renderEach`：单子节点 ✅，多子节点需用户用 Fragment 包裹
- `when` 的惰性分支：同上
- 组件模式：`Array.isArray(result)` 处理多子节点 ✅
- `processChildren`：数组被扁平化 ✅
