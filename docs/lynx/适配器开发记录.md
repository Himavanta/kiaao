# Kiaao Lynx 适配器开发记录

## 背景

Kiaao 是一个纯运行时的响应式 UI 框架。Lynx 是字节跳动的跨端渲染引擎。本文档记录 kiaao 适配 Lynx 过程中的技术决策、问题和解决方案。

---

## 一、文件结构

```
src/lynx/
  types.ts              Lynx 原生 API 类型声明（__CreateElement 等）
  events.ts             事件前缀检测（bindtap → __AddEvent）
  adapter.ts            RenderAdapter 实现
  jsx-runtime.ts        JSX runtime 桥接（复用主 JSX runtime）
  index.ts              平台入口（全局钩子 + render + 导出 core）

packages/lynx/
  lynx.config.ts        Rspeedy 构建配置
  src/index.tsx         用户应用入口
```

## 二、开发历程

### 阶段 1：基础 adapter

**状态**：完成

实现了 `RenderAdapter` 的全部必须方法：

- `el()` → `__CreateElement`
- `text()` → `__CreateRawText`
- `comment()` → `__CreateWrapperElement`
- `before()` / `append()` / `remove()` / `clear()` / `setText()` / `replace()`
- `setProp()` — 属性/样式/事件分发（事件名直接使用 Lynx 前缀：`bindtap`）
- `isNode()` / `isElement()`

### 阶段 2：JSX 编译

**问题**：`Can't find variable: React`

**原因**：SWC 默认使用 classic JSX 编译方式，生成 `React.createElement`。`pluginReactLynx()` 原本负责配置 SWC，移除后 SWC 回到了默认行为。

**解决**：在 `lynx.config.ts` 中配置 `tools.swc`：

```ts
tools: {
  swc(config) {
    config.jsc.transform.react = {
      runtime: "automatic",
      importSource: "kiaao/lynx",
    };
  },
}
```

### 阶段 3：`__CreateWrapperElement`

**问题**：`Can't find variable: __CreateWrapperElement`

**原因**：此 API 在 Lynx SDK 1.4.0 上不存在，可能是在新版本才加入的。

**解决**：改用 `__CreateElement("view", pageId)` 并设零尺寸样式替代。

### 阶段 4：全局钩子

**问题**：

- `TypeError: processData is not a function`
- `TypeError: renderPage is not a function`

**原因**：Lynx 运行时需要以下全局函数：

```
globalThis.renderPage      创建 page 并启动渲染
globalThis.processData     数据处理（可为空）
globalThis.updatePage       更新通知（可为空）
globalThis.runWorklet       执行工作集（ReactLynx 提供）
```

**尝试**：在 `src/lynx/index.ts` 中用 `Object.assign(globalThis, {...})` 设置。
**结果**：全局钩子跑在后台线程，主线程看不到。

## 三、核心问题：双线程架构

### Lynx 的双线程模型

| 线程                          | 运行环境                      | 能力                        |
| ----------------------------- | ----------------------------- | --------------------------- |
| 主线程（Main Thread）         | Lepus 引擎，ES2019            | 原生 API 可访问，布局、渲染 |
| 后台线程（Background Thread） | PrimJS/JavaScriptCore，ES2015 | 业务逻辑，事件处理          |

`__CreateElement`、`__CreatePage` 等原生 API **只在主线程可用**。
`globalThis.renderPage` 需要在主线程上设置，因为 Lynx 在主线程调用它。

### 三种框架的线程策略

| 框架             | 架构                              | 原理                                                                                             |
| ---------------- | --------------------------------- | ------------------------------------------------------------------------------------------------ |
| **ReactLynx**    | `pluginReactLynx()` Rspeedy 插件  | 自动入口分层 + `@lynx-js/react-webpack-plugin` 处理主/后台分离                                   |
| **Vue-Lynx**     | `pluginVueLynx()` Rspeedy 插件    | 显式 `LAYERS.MAIN_THREAD` / `LAYERS.BACKGROUND` 分层，`VueMarkMainThreadPlugin` 处理启动代码生成 |
| **SolidJS 示例** | 原生 Rspack（`rspack.config.js`） | **单入口，整个 bundle 标记为主线程**。代码在主线程执行，直接设全局钩子                           |

### SolidJS 模式详解

SolidJS 示例项目（`examples/with-solidjs`）使用原生 Rspack，通过自定义插件将 `main.js` 标记为 `lynx:main-thread: true`，整个 bundle 在主线程执行：

```js
// rspack.config.js
compiler.hooks.thisCompilation.tap("MarkMainThreadWebpackPlugin", (compilation) => {
  compilation.hooks.processAssets.tap("MarkMainThreadWebpackPlugin", () => {
    const asset = compilation.getAsset("main.js");
    compilation.updateAsset(asset.name, asset.source, {
      ...asset.info,
      "lynx:main-thread": true,
    });
  });
});
```

SolidJS 适配器代码：

```ts
globalThis.renderPage = function () {
  page = __CreatePage("0", 0);
  pageId = __GetElementUniqueID(page);
  _render(code, page);
};
```

## 四、Rspeedy vs 原生 Rspack

|                   | Rspeedy（当前方案）       | 原生 Rspack（SolidJS 方案） |
| ----------------- | ------------------------- | --------------------------- |
| 配置文件          | `lynx.config.ts`          | `rspack.config.js`          |
| JSX 编译          | 需手动配 `tools.swc`      | 可配 `builtin:swc-loader`   |
| 入口模型          | 自动分层（主/后台）       | **单入口，全主线程**        |
| 对 kiaao 适配难度 | 高（需写 Rspeedy plugin） | 低（简单标记即可）          |
| 参考项目          | ReactLynx, Vue-Lynx       | SolidJS 示例                |

**决策**：先尝试**原生 Rspack + 单入口主线程模式**（SolidJS 路线），如果遇到限制再考虑写 Rspeedy plugin。
